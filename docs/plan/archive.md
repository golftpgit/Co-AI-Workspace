### u18-เต็ม

****หน้าตาที่ยังไม่ได้ทำ — จาก Bionic/LM Studio** *(ดูของจริงตอน P5.4, 2026-08-12)***

**สถานะจริง**

สามอย่างที่ Bionic ทำแล้วเรายังไม่มี: (1) **ตัวเลือกโมเดลอยู่ในช่องพิมพ์** ไม่ใช่ในหน้า settings — โมเดลเป็นการตัดสินใจต่อเทิร์น (2) **`Context: 5.8K` ค้างอยู่ท้ายจอตลอด** — ของเราแสดงตอนย่อครั้งเดียวแล้วหาย (3) **`Worked for 12s ›` พับ reasoning ไว้** กดแล้วค่อยกาง — ตอนนี้ของเราสตรีม reasoning ทิ้งไปเฉยๆ · จาก LM Studio: **ปุ่ม eject/สถานะ "โหลดอยู่ในหน่วยความจำ"** ต่อโมเดล ซึ่งตรงกับที่ §9.4 ต้องการอยู่แล้ว (คืน RAM เมื่อไม่ใช้)

**ต้องทำอะไรถึงจะปิดได้**

🔶 **ทำแล้วสามในสี่ (2026-08-12)** — (1) **ตัวเลือกโมเดลอยู่ในช่องพิมพ์แล้ว** เห็นชื่อโมเดล Tier 0.5 และสลับได้โดยไม่ออกจากหน้าแชท (ยืนยันบนหน้าจอ: `Qwen3-VL-4B-Instruct-4bit ⌄`) (2) **มิเตอร์บริบทค้างอยู่ท้ายช่องพิมพ์** — `TurnEvent.usage` ใหม่รายงานทุกครั้งที่โมเดลตอบ ไม่ใช่โผล่ครั้งเดียวตอนย่อ (เปลี่ยนเป็นสีส้มที่ 75% ซึ่งคือจุดที่ §5.6 เริ่มย่อ) (3) **ปุ่มปลดจากหน่วยความจำ** โผล่เมื่อโมเดลโหลดอยู่ — คืน RAM โดยไม่ต้องปิดอะไร · **(4) `คิดอยู่ N วินาที ›` ทำแล้ว (2026-08-16, 2 เทส + 2 กฎ)** — runner เคย**ทิ้ง `reasoningDelta` ทุกตัว** พร้อมคอมเมนต์ว่ายังไม่มีที่แสดง ตอนนี้สะสมแล้วส่งเป็น event ของตัวเอง การ์ดพับไว้เหนือคำตอบและกางได้ · **กฎที่ทำให้การทิ้งมันเคยปลอดภัย ต้องอยู่ต่อ**: ความคิดไม่ใช่คำตอบ — พอมันไปรวมกับ `text` เมื่อไหร่ มันจะถูกบันทึกเป็นคำตอบและถูกส่งเข้า structured-output parser (เทสยืนยันว่าข้อความที่เก็บคือคำตอบล้วน · check.sh fail ถ้ามี `text +=` ในเคสนั้น) · ไม่นับเป็นเทิร์นในบทสรุป และไม่ถูกบันทึกลงบทสนทนา — การ์ดบอกไว้ตรงนั้น (ตั้งใจ ตาม §14.2 ว่าเป็นงานของ Live Monitor) · ยังไม่ได้เห็นมิเตอร์กับปุ่ม eject บนหน้าจอ (ต้องรันเทิร์นก่อน มิเตอร์ถึงมีตัวเลข)

### สิ่งที่ต้องทำทุกครั้ง ไม่ใช่ครั้งเดียว

1. **ขับหน้าจอด้วยมือหลังทุก task ที่มี UI** — สถิติของโปรเจกต์นี้: ทุกรอบเจอบั๊กที่เทสทั้งชุดมองไม่เห็น (8 · 10 · 5 · 7 · 7 · 3) แล้วบันทึกลง [`docs/DRIVING_LOG.md`](../DRIVING_LOG.md)
2. **`./scripts/build-app.sh` ก่อนขับทุกครั้ง** — และเทียบเวลาไฟล์ binary กับเวลาเริ่มโปรเซสก่อนอ่านผล (เคยอ่านหน้าจอของ build เก่าแล้วสรุปผิดมาแล้ว)
3. **ปิดแอปด้วย ⌘Q เสมอ** — `kill -9` ทำให้ macOS restore เป็น "ไม่มีหน้าต่าง" ซึ่งหน้าตาเหมือน boot ล้มเหลวเป๊ะ (U24-2)
